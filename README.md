# PhantomFlow
A clean, hideable, and fast side-chat interface powered by Groq that you can inject onto almost any website.

How to run PhantomFlow

1. Go to Groq Console and create an account.
2. Generate an API key.
3. Copy the key and store it somewhere secure.
4. Open your preferred browser.
5. Press Ctrl + Shift + I to open Developer Tools.
6. Type allow pasting into the console and press Enter.
7. Paste the code from PhantomFlow.js into the console and press Enter.
8. When prompted, paste your API key and press Enter.
   You now have your own side AI chatbot running directly in your browser.
