# PhantomFlow
A clean, hideable, and fast side chat interface powered by Groq that you can inject on any website.

How to run PhantomFlow

1. Go to https://console.groq.com/keys and make an account
2. Make a API Key, copy it, save the secret key somewhere very secure
3. Go to your prefered browser and do ctrl + shift + i
5. Write "allow pasting" and press enter
6. Paste the javascript code at PhantomFlow.js and press enter
7. When it asks for the key, paste the key and press enter
    You now have your very own side AI chatbot
